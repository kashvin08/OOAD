# Object Oriented Analysis & Design (OOAD)
# Role-Based Project Evaluation System

-------------------------------------------------------------------------------
A Java-based system designed using OOAD principles to manage project evaluations through a role-based access architecture. The system supports multiple user roles, each with dedicated 
functionalities and dashboards

Roles:

1. Student: i) Submit project details including title, abstract, and type.
            ii) Manage and track submission status

2. Coordinator: i) Assign evaluators to students
                ii) Create and manage evaluation time slots
                iii) Monitor awards
                iv) Generate evaluation reports

3. Evaluator:   i) Review submitted projects and documents
                ii) Provide ratings based on a predefined evaluation scale
-------------------------------------------------------------------------------

Key Features:

1. Role-Based Access Control (RBAC) - Ensures each user has access only to features relevant to their role

2. Structured Evaluation Workflow - Streamlines submission, assignment, and assessment processes

3. Report Generation & Award Monitoring - Enables coordinators to track performance and manage awards efficiently
